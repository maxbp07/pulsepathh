# Mensaje WhatsApp — captación preflight

Copiar/pegar. Ajustar el nombre si hace falta. **Sin promesas médicas ni ML.**

## Primer contacto

```
Hola! Estoy lanzando un preflight de PulsePath: una app de ~2–3 min/día
para medir alerta/fatiga con un test de tiempo de reacción (PVT) y
cuestionarios de bienestar laboral.

Busco 30 personas que la usen 14 días. Es anónima (código, sin nombre en
el servidor), gratis, y me ayuda a validar el protocolo antes de un piloto
en empresa.

¿Te apuntas? Te mando un código PP-2026-XXX y el enlace de la app.
```

## Tras aceptar (código + enlace)

```
Genial, gracias!

App: https://app.getpulsepath.com/
Tu código: PP-2026-XXX

Pasos: abrir la app → introducir código → aceptar el consentimiento →
hacer el check-in del día (sueño + KSS + PVT) y, el primer día, la
evaluación D0 (DASS-21 + GAD-7 + CBI).

Cualquier duda o bug, escríbeme por aquí. ¡Gracias!
```

## Recordatorio 48 h sin check-in

```
Hola! Solo un toque amable del preflight PulsePath: si puedes, abre la
app y completa el check-in de hoy (~2–3 min). Si algo falla al sincronizar,
dímelo. ¡Gracias!
```

## Aviso D6 / D13 (evaluaciones)

```
Mañana toca la evaluación de estudio (D7 o D14): DASS-21 + GAD-7 + CBI
en la sección Estudio de la app, además del check-in diario. Cualquier
duda, aquí estoy.
```

## Qué no escribir

- Diagnóstico, “depresión”, “ansiedad clínica”, “burnout diagnosticado”
- “Entrenamos IA / ML con tus datos”
- Avales de Basner, NASA u organismos como endorsement comercial
